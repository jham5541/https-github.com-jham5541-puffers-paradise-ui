# Player Servers and Moderation

Players can create their own servers using **controlled server templates** —
never raw server binaries or arbitrary code.

## Server types

Official public, private friend, roleplay, PvP, business simulation, racing,
creative building, hardcore survival, story-focused.

## Server owner controls

Server name, description, player capacity, public/private, invite codes,
whitelist, starting money, economy multiplier, crime difficulty, police
response, PvP zones, property prices, building limits, death penalties, vehicle
availability, mission availability, voice-chat rules, roleplay rules, admin
permissions, content restrictions.

## Moderation tools

Kick, temporary ban, permanent ban, mute, jail/timeout area, spectator mode,
report review, chat logs, transaction logs, asset rollback, building removal,
organization suspension, permission auditing.

## Hard limits on server owners

Server owners **never** get access to player personal information or payment
data. Bans are per-server; platform-level enforcement stays with us. All
moderation actions are themselves logged and auditable.

## Voice chat

Moderated provider (Vivox or equivalent) with per-server rules, push-to-talk
defaults, and platform-compliant reporting.
