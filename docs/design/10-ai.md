# Artificial Intelligence (NPCs)

AI systems are needed for: pedestrians, traffic, police, criminal factions,
store workers, tenants, customers, employees, mission enemies, emergency
responders, construction workers.

## NPC model

NPCs have: daily schedules, jobs, homes, needs, relationships, reactions to
crime, memory of recent events, faction loyalty, fear and aggression levels.

## Implementation strategy

- **v1: state machines and behavior trees** (UE5 Behavior Trees + State Trees),
  not generative AI per NPC. Deterministic, cheap, debuggable.
- **Mass Entity** for crowds, pedestrians, traffic, and ambient simulation —
  thousands of lightweight agents, promoted to full actors only near players.
- Perception (sight/sound) drives crime witnessing, which feeds the heat
  system (docs/design/06-combat-and-heat.md).
- Schedules run on a simulation LOD: full fidelity near players, statistical
  simulation far away.
