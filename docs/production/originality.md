# Originality Requirements

"GTA-style" describes the genre, never the content. The project must have its
own:

- Name
- City
- Story
- Characters
- Factions
- Dialogue
- Music
- UI (no copied weapon wheel / HUD trade dress)
- Map
- Brands
- Vehicles (fictional manufacturers, no near-clone trade dress)
- Buildings
- Mission designs
- Art direction
- Logos
- Economy
- Progression system

Additional rules:

- Gang content uses original names and iconography — nothing borrowed from
  real-world gangs.
- No celebrity likenesses without permission.
- Illegal-business gameplay stays fictionalized and mechanical.
- Every published UGC item passes copyright screening before it goes live.
