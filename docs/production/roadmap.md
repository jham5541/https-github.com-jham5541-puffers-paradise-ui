# Development Phases

## Phase 1 — Gameplay prototype
Character controller, camera, one vehicle, one weapon, one NPC, one mission,
small test map, basic multiplayer.

**Exit criteria:** two players can drive, shoot, and complete the mission
together on a dedicated server build.

## Phase 2 — Core systems
Inventory, economy, combat, heat system, vehicles, character customization,
missions, properties, organizations.

## Phase 3 — Construction and businesses
Land ownership, modular building system, interior system, rentals, business
management, employee roles, shared organization accounts.

## Phase 4 — Persistent online world
Dedicated server fleet, database, matchmaking, authentication, server browser,
moderation, anti-cheat, transaction logging.

## Phase 5 — Content production
City districts, missions, characters, vehicles, clothing, interiors,
businesses, factions, music, sound effects.

## Phase 6 — User-generated content
Mission editor, server rules editor, building publishing, business templates,
community moderation, creator marketplace.

---

Each phase ships a playable build. Nothing in phase N+1 starts until phase N's
exit criteria are demoable.
