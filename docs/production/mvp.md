# Minimum Viable Product

The first playable version does **not** include everything.

## MVP map

- One city district
- One residential area
- One commercial strip
- One industrial zone
- One police station
- One hospital
- One construction lot

## MVP gameplay

- Third-person movement
- Driving
- Shooting and melee
- Police response (heat tiers 1–4)
- Character creation
- **8 main missions**
- **20 side missions**
- **4 businesses** (taxi company, convenience store, nightclub, construction company)
- Property purchasing
- Apartment renting
- **One player-buildable flow** covering four building types
  (small house, store, office, gang clubhouse)
- Team creation
- Gang creation
- Dedicated multiplayer server, **16–32 players**
- Basic economy with transaction logging
- Inventory
- Vehicle ownership
- Saving and loading

## Definition of done

A new player can: create a character, do a mission, earn money, buy a car,
rent an apartment, join or found a gang, buy a lot, build a small house, and
log back in tomorrow to find all of it still there — on a 32-player server.
