# Team Required

For a credible commercial build:

- Game director
- Technical director
- Lead gameplay programmer
- Network engineer
- Backend engineers
- AI programmer
- UI programmer
- Technical artists
- Environment artists
- Character artists
- Vehicle artists
- Animators
- Level designers
- Mission designers
- Economy designer
- UI/UX designer
- Sound designers
- Composer
- Writers
- QA engineers
- DevOps engineer
- Security engineer
- Community and trust-and-safety staff
- Legal counsel

A polished full-scale game of this type is normally a **large studio project**.
A smaller team should focus first on **one district and one complete gameplay
loop** (see mvp.md) — that is exactly what this repo is scoped to.
